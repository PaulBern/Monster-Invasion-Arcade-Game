# Monster Invasion Arcade 

A fast-paced top-down arcade shooter built with Python and Pygame. Survive waves of invading robots, collect strategic loot, and master different weapon types to achieve the high score!

## Background & Features
This project is slightly optimizated version of my final submission for the **University of Helsinki's MOOC.fi Advanced Course in Programming**. 

I developed cool features for exampe:

*   **Dynamic Arsenal:** Each weapon (MG, Shotgun, Rocket Launcher) features unique fire rates, damage, and projectile behavior.
*   **Loot System:** Defeated enemies drop points (Coins), healing (Crosses), or new weapons.
*   **Challenging Gameplay:** The difficulty scales over time, requiring quick reflexes and tactical movement.
*   **Clean Architecture:** Object-oriented design for easy extension of game objects and items.

## Installation & Setup

**Clone the repository:**
   git clone [https://github.com/YOUR_USERNAME/Monster-Invasion-Arcade.git](https://github.com/PaulBern/Monster-Invasion-Arcade.git)
   cd Monster-Invasion-Arcade

    Install Dependencies:
    Ensure you have Python 3.x installed. Install the required libraries via pip:
    Bash

    pip install -r requirements.txt

    Run the Game:
    Bash

    python main.py

Controls
    W, A, S, D: Move the Robot
    Mouse: Aim and Shoot
    H: Toggle In-Game Help Menu
    ESC: Quit Game

Project Structure

    main.py: The core game engine and logic.

    assets/: Directory containing all custom pixel art sprites.

    requirements.txt: List of necessary Python libraries (Pygame, Numpy).

    LICENSE: MIT License information.
